# 清爽阅读界面

## 来源与范围

2026-09-15，用户明确要求取消出版物风格，按宝玉设计 skills 重做面向普通读者的博客，并直接更新项目。该要求替代 project-documents#52 第 6 节的视觉方向；导航、内容模型、技术栈、阅读功能和离线边界保持不变。

设计方法读取自 agent-plugin-marketplace 的 `design/visual-artifact-design`，并校验 baoyu-design 上游快照 `026d4ea012bdd5cada72ac8cc13f21ba4edf2245`，使用 hi-fi-design / interactive-prototype 方法。生产实现使用现有 Astro、原生 CSS 和原有浏览器脚本，不引入原型工具的 React/Babel 依赖。

## 视觉与信息层级

- 浅灰页面背景、白色阅读表面、少量蓝色链接与选中态；深色使用对应语义变量，不采用渐变、仿纸张或装饰性封面。
- 系统无衬线字体，无外部字体请求。文章标题先于摘要与元信息。首页直接进入最近文章，专题接在文章之后；分类、标签和归档是辅助浏览入口。
- 顶部使用小尺寸站名与常规导航。删除英文装饰眉题、补零计数、文章序号及泛化品牌口号。外部专题保留明确的外站提示；内部文章链接不使用外链箭头。
- 内容少时自然收缩，不造文章、阅读量、封面或更新日期。所有分类、标签、归档和专题继续来自真实集合。
- 桌面正文约 740px，默认 18px / 1.85 行高；手机使用全宽阅读表面与 20px 内边距。正文仍支持 16–26px 设置。
- 目录默认收起，使用原生 details 和可键盘操作的 summary。顶部进度条继续显示进度，百分比输出保留为辅助信息；续读不会自动跳转。

## 样式约定

`src/styles/site.css` 维护 `--paper`、`--surface`、`--ink`、`--muted`、`--rule`、`--soft`、`--accent` 等浅深色语义变量。浏览器 theme-color 从 `--paper` 同步，避免 JavaScript 维护另一套配色。Manifest 保持同样的默认浅色启动背景。

容器圆角用于区分阅读表面、输入和独立专题入口，不给每段文本增加卡片。只有弹窗、短暂通知使用阴影。正文和侧栏无持续动画，尊重 reduced-motion。

## 验证义务

原有检查、单测、构建及端到端用例全部保留。新增浏览器用例验证：首页标题在首屏、无装饰编号/封面、目录折叠与键盘展开、320px 窄屏与 26px 字号、跳转正文、弹窗焦点返回、关键文本对比度及浅深色 theme-color。截图来自实际构建页面，作为视觉复核证据，不伪装成全面像素基准测试。
